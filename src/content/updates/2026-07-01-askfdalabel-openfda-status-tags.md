Today we added openFDA-sourced status tags to the label view page and a distinct visual theme for archived and earlier-version labels.

### Key Milestones

- **openFDA Status Tags:** Added a Current/Archived status tag to the label view page, sourced from openFDA.
- **SetID Availability Checks:** Added checks for SetID availability across openFDA, DailyMed, and the public FDALabel version, then dropped the DailyMed check to keep only openFDA and public FDALabel.
- **Archived Label Theming:** Added an Earlier Version tag and banner for older SPL versions, applying a distinct archived visual theme.
- **Admin AI Model Management:** Added system-admin-level AI model management, along with a themed view for archived labels.
